## MODIFIED Requirements

### Requirement: Agentic Reply

The service SHALL reply to any incoming text message with a response generated by a LangChain built-in agent loop backed by the configured language model. The agent SHALL be constructed once using a built-in LangChain agent construct configured with the phaze3 read-only filesystem tools, and the message handler SHALL run the agent for the incoming text and reply with the model's answer. Producing a reply MAY involve one or more tool-calling turns in which the agent invokes the filesystem tools and incorporates their results. The handler SHALL remain modelled as an Effect and executed on the service's Effect runtime.

#### Scenario: User sends a text message

- **WHEN** a user sends any text message to the bot
- **THEN** the service runs the agent loop with that message and replies in the same chat with the model-generated answer

#### Scenario: Reply targets the originating chat

- **WHEN** the bot replies to an incoming message
- **THEN** the generated reply is delivered to the chat from which the message originated

#### Scenario: Answer grounded in files

- **WHEN** a user asks about files under the sandbox root
- **THEN** the agent may call the read-only filesystem tools and produce a reply grounded in the tool results

#### Scenario: Model call fails

- **WHEN** the language model request fails or returns no content
- **THEN** the failure is reported via `Effect.logError`, the bot replies with a graceful fallback message, and long-polling continues uninterrupted
